# 3 โหมด multi-agent — เลือกยังไง

> สรุปสั้นจาก [stands-compose101.md](./stands-compose101.md) ข้อ6
> ตัวเลขทั้งหมดวัดจากการรันจริงบน ollama + qwen3.5 ในโปรเจกต์นี้

คำถามเดียวที่แยก 3 โหมดออกจากกันคือ

> **"ใครตัดสินว่าใครทำต่อ — และตอนที่เขาตัดสิน เขารู้อะไรบ้าง"**

ไม่ใช่ *"LLM ตัดสิน หรือ เราตัดสิน"* เพราะ delegate กับ swarm ก็ LLM ตัดสินทั้งคู่

---

## graph — คนตัดสินคือคุณ ตอนที่ยังไม่มีข้อมูลอะไรเลย

```
คุณเขียน edges ไว้ตั้งแต่แรก   researcher → notetaker
                                    │
รันจริง:  researcher ทำงาน ────────┘
          notetaker  ทำงาน        ← ไม่มีใครตัดสินอะไรทั้งนั้น เดินตามท่อ
```

LLM **ไม่มีสิทธิ์เลือก** เลยสักนิด — เลือกได้แค่ "จะเรียก tool ตัวไหนในมือตัวเอง" ไม่ใช่ "ใครทำต่อ"

คนตัดสิน = **คุณ ตอนพิมพ์ YAML** ซึ่งเป็นเวลาที่ยังไม่เห็นข้อมูลสักตัว

## delegate — คนตัดสินคือหัวหน้าที่ไม่ได้จับงาน

```
coordinator  ← ตัดสิน แต่ไม่เคยทำงานเอง (config เราไม่ให้ tool มันสักตัว)
  │
  ├─> researcher  ทำงาน → ส่งผลกลับ → หมดหน้าที่
  │
  └─> notetaker   ทำงาน → ส่งผลกลับ → หมดหน้าที่
```

`researcher` กับ `notetaker` **คุยกันเองไม่ได้** ไม่รู้ด้วยซ้ำว่าอีกฝ่ายมีตัวตน
มันเห็นแค่ prompt ที่หัวหน้าส่งมา ทำเสร็จก็ส่งกลับ จบ

## swarm — คนตัดสินคือคนที่เพิ่งทำเสร็จ

```
researcher ทำงานเอง → ตัดสินเองว่า "ต่อไป writer"
     ↓
writer     ทำงานเอง → ตัดสินเองว่า "ต่อไป reviewer"
     ↓
reviewer   ทำงานเอง → ตัดสินเองว่า "ผ่าน ส่ง notetaker" หรือ "ไม่ผ่าน ส่งกลับ writer"
```

ไม่มีหัวหน้า **คนที่มือเปื้อนงานอยู่คือคนตัดสิน**

---

## หลักฐานจากที่รันจริง — ดูว่าใครพูดประโยคสุดท้าย

**graph**
```
execution_order: ['researcher', 'notetaker']
```
`notetaker` พูดท้าย — แต่ **รู้ตั้งแต่ก่อนรันแล้ว** เพราะเราเขียน edge ไว้เอง

**delegate**
```
[team] -> notetaker {'input': 'delegate-test.md: ...'}
[notetaker] -> save_note {...}

token:  team 949/172   notetaker 895/136
```
`team` มีเลข token **หลัง** notetaker เสร็จ = หัวหน้ากลับมาพูดอีกรอบเพื่อสรุป
→ คำตอบสุดท้ายออกจากปาก **coordinator**

**swarm**
```
node_history: researcher → writer → reviewer → notetaker
```
`researcher` ไม่ได้กลับมาพูดอีกเลย → คำตอบสุดท้ายออกจากปาก **notetaker**
และ **ไม่มีทางรู้ล่วงหน้า** ว่าจะเป็นใคร ถ้า reviewer ตีกลับ path จะยาวกว่านี้

---

## ทำไมถึงสำคัญ — คนตัดสินรู้อะไรตอนตัดสิน

| | graph | delegate | swarm |
|---|---|---|---|
| ใครตัดสิน | **คุณ** | coordinator | คนที่เพิ่งทำเสร็จ |
| ตัดสินตอนไหน | ตอนเขียน YAML | ก่อนงานเริ่ม | **หลัง** ทำงานเสร็จ |
| ตอนตัดสินมีข้อมูลอะไร | ไม่มีเลย | prompt + `description` | prompt + `description` + **ผลงานจริงที่เพิ่งทำ** |

**ตัวอย่าง: researcher ค้นแล้วเจอว่าข้อมูลขัดแย้งกัน**

- **swarm** → researcher รู้ตัวเลย ปักธงส่ง `reviewer` ทันที เพราะเห็นข้อมูลกับตา
- **delegate** → coordinator ต้องอ่านผลที่ส่งกลับมาก่อน แล้วค่อยเรียก reviewer อีกรอบ (ยิง model เพิ่ม 1 ครั้ง)
- **graph** → ถ้า YAML ไม่มี edge ไป reviewer ก็คือ **ไม่มีทางไป** ต่อให้ข้อมูลพังแค่ไหน

---

## ตารางสรุป

| | graph | delegate | swarm |
|---|---|---|---|
| ลูกทีมส่งงานหากันเองได้ไหม | ไม่ได้ (ท่อวางไว้แล้ว) | **ไม่ได้** | ได้ |
| ทำเสร็จแล้ว control ไปไหน | ไหลตาม edge ไม่กลับ | **กลับหาหัวหน้า** | ไปหาคนถัดไป ไม่กลับ |
| ใครพูดประโยคสุดท้าย | node ท้ายท่อ (รู้ล่วงหน้า) | หัวหน้า | คนสุดท้ายที่ถือไม้ (**ไม่รู้ล่วงหน้า**) |
| ทุกตัวได้รันไหม | **ครบแน่นอน** | เฉพาะคนที่หัวหน้าเรียก | เฉพาะคนที่ถูกเอ่ยชื่อ |
| โครงสร้าง | ท่อประปา (วางไว้แล้ว) | เรียกฟังก์ชัน (มี stack) | ส่งไม้ผลัด (ทางเดียว) |
| token ที่วัดจริง | 3,616 | **2,204** | 18,474 (4 ตัว) |

## เปรียบเทียบแบบออฟฟิศ

**graph** = สายพานโรงงาน ชิ้นงานไหลผ่านทุกสถานีตามลำดับที่ติดตั้งไว้
— **ไม่มีใครตัดสินใจอะไรระหว่างทาง เปลี่ยนลำดับต้องปิดไลน์มาแก้**

**delegate** = หัวหน้าแจกงาน ลูกน้องทำเสร็จส่งกลับโต๊ะหัวหน้า หัวหน้าอ่านแล้วค่อยตัดสินว่าส่งต่อใคร
— **ทุกอย่างผ่านโต๊ะหัวหน้า**

**swarm** = ไม่มีหัวหน้า ทำเสร็จแล้วเดินไปวางบนโต๊ะเพื่อนที่ควรทำต่อเอง
— **ไม่มีใครเห็นภาพรวม แต่คนหน้างานรู้ดีกว่า**

---

## หลักเลือกประโยคเดียว

> **รู้ลำดับอยู่แล้ว → graph · ต้องมีคนคุมและสรุป → delegate · อยากให้คนที่เห็นงานจริงเป็นคนตัดสิน → swarm**

ราคาที่จ่ายเรียงกันพอดี:
graph ถูกและคาดเดาได้ · delegate ถูกสุดแต่หัวหน้าเป็นคอขวด · swarm แพงสุดเพราะทุกคนต้องพกกระดานทั้งใบไปด้วย
