# การทำงานของ Swarm และ Handoff

## Handoff คืออะไร
เป็นกระบวนการที่หนึ่ง agent ส่งต่อให้อีก agent ทำงานต่อเมื่อต้องการความช่วยเหลือเฉพาะทางหรือจบขั้นตอนนั้น

## การทำงานร่วมกัน
- แต่ละ agent มีหน้าที่ชัดเจน เช่น http_request สำหรับเรียก API, file_read สำหรับอ่านไฟล์, handoff_to_agent เพื่อส่งต่อให้ notetaker บันทึก
- เมื่อต้องบันทึกงาน ให้ใช้ handoff_to_agent ส่งงานไปให้ notetaker

## ตัวอย่าง workflow
- รับคำสั่ง → รวบรวมข้อมูล → จัดเตรียมเนื้อหา → ส่งต่อให้นotetaker เก็บไฟล์

## ข้อจำกัดของแต่ละ agent
- http_request: ทำ HTTP requests เท่านั้น
- file_read: อ่านไฟล์เท่านั้น ไม่สามารถเขียนได้
- notetaker: บันทึกไฟล์ลง disk เท่านั้น ไม่ท่องเว็บได้

## ประโยชน์
ทำให้ระบบมีประสิทธิภาพ มีส่วนแบ่งงานชัดเจน และทำงานต่อได้อย่างต่อเนื่อง
